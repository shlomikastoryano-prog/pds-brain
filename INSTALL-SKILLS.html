PDS skills: install and use

The skills give your AI tool the rules of the phenom-ds design system. The tool reads them when your task needs them, so you do not paste rules into your prompt.

Install on a Mac (2 minutes)

  1. Unzip pds-skills.zip.
  2. Double-click install-skills.command.
    The first time, macOS may block it. Right-click the file, choose Open, then Open again. This happens once.
  3. The command copies the skills to ~/.claude/skills (Claude Code) and ~/.cursor/skills (Cursor). Wait for "Done".
  4. Start a new Claude Code session, or restart Cursor.

Prefer the terminal? Run ./install-skills.sh from the unzipped folder.

Claude Code

Terminal or Claude Desktop

  1. Open a session in the phenom-ds folder.
  2. Type / and look for names that start with pds-. If you see them, they are installed.
  3. Work as usual. Claude picks a skill when your task matches. You can also name one: 
    Use pds-definition-of-done on my current change.
  4. To confirm a skill was used, look for a Skill(pds-…) line in the conversation, followed by Read lines.
Cursor

Agent chat

  1. Restart Cursor after the install.
  2. Open the phenom-ds folder and start the agent.
  3. Ask for a skill by name: 
    Use the pds-angular-guidelines skill and review this component.
Whether Cursor loads skills depends on your Cursor version. If you do not see them, the AGENTS.md file in the phenom-ds branch gives Cursor the same guidance.

Try it

Paste this into Claude Code, in a branch with a small change:

Check whether the current change is ready for a PR. List which skills and files you read.

You should see pds-definition-of-done used and its reference files read.

Good to know

  • The skills are generated from the team brain (pds-brain). Do not edit them: the next update overwrites your changes. To change a rule, change the brain.
  • To update, get the new pds-skills.zip and run install-skills.command again. It replaces the old copies.
  • Items marked "Open" or "suggestion" in the skills are not decided yet. The tool should say so when it relies on one.
